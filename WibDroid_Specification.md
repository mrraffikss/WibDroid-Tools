# WibDroid Tools — спецификация

Локальное приложение Flask для управления Android через ADB/Fastboot. Сервер намеренно слушает только `127.0.0.1:8765`. Команды выполняются через `subprocess.Popen`, с таймаутом, захватом stdout/stderr и понятными ошибками.

## Безопасность

Модуль APK Security выполняет локальную эвристическую проверку архива, вычисляет SHA-256 и проверяет базовую структуру APK/APKS/XAPK/APKM. Это **не антивирус промышленного уровня**: приложение не обещает обнаружение всех вредоносных программ, не загружает файлы в интернет и не обходит защиту Android. Опасные операции Fastboot должны добавляться только с явным подтверждением пользователя.

## Расширение

Добавляйте blueprints в `api/`, команды в `adb/` и `fastboot/`, сборщики в `device/`, отчёты в `reports/`, макросы в `automation/`, плагины в `plugins/`; для каждой функции нужны тесты и обработка отсутствующего устройства.
